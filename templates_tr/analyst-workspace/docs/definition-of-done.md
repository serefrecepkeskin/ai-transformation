# Bitmişlik Tanımı (DoD) — şirket temeli

> **PLACEHOLDER** — mühendislik liderliğiyle onayla, sonra bu notu kaldır.
> Her görevin DoD bölümü bu listeden başlar; görevler madde ekler, çıkarmaz.

Bir değişiklik şu koşullarda bitmiştir:

- [ ] Görevdeki tüm kabul kriterleri kanıtlanabilir şekilde karşılandı
- [ ] Kalite kapıları yeşil (typecheck/build, lint, format, test)
- [ ] Yeni davranış en az bir otomatik testle kapsandı; hata düzeltmesi ise
      hatayı yeniden üreten bir testle
- [ ] Arayüz değişiklikleri PR'da tarayıcı kanıtı taşıyor (ekran görüntüsü,
      temiz konsol)
- [ ] Kullanıcıya görünen metin i18n'den geçiyor (hardcoded string yok)
- [ ] Değişiklikten etkilenen doküman/ADR'lar aynı PR'da güncellendi
- [ ] Öz-inceleme bulguları (kritik/orta) düzeltildi
- [ ] PR merge edildi ve test ortamına dağıtıldı
- [ ] TODO(confirm): şirkete özel maddeler (güvenlik incelemesi? izleme?
      sürüm notları?)
