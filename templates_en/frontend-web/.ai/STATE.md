# Feature State — PLACEHOLDER: branch or feature name

> **Contract.** Cross-session memory for the feature on this branch — the one
> thing an agent reads to know where the work stands.
>
> - **Written by** `implement-task`, as its final step. Not a separate ritual.
> - **Lives** with the feature branch; **deleted when it merges**. Anything
>   permanent moves to an ADR or `docs/` first — this file is never the
>   long-term home of a decision.
> - **Limit: 60 lines.** If it does not fit, the feature is too big — split it.
>   The limit is the warning signal, not just a budget.

## Feature & goal

PLACEHOLDER: one or two lines — what this feature is and what "done" means for
it (the acceptance target, not the task list).

## Done

- PLACEHOLDER: a completed step and the evidence that it works (test name,
  endpoint call, browser check).

## Next

- PLACEHOLDER: the next concrete step. Smallest first; if the next step is
  unclear, that is what to write down.

## Open decisions awaiting ADR

- PLACEHOLDER: a choice that has been made in code but not yet recorded. Run
  `record-decision` when it settles — then delete the line from here.

## Handed-over TODO(confirm) items

- PLACEHOLDER: a question only a human can answer, and who was asked.
